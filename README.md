# Маршрут

Этот снимок содержит исходники клиента Google Play 0.40 (код 40), а также общий код Android и macOS. Для сборки Play используйте `zsh play/build.zsh КАТАЛОГ_АРТЕФАКТОВ_ANDROID BUNDLETOOL_JAR НОВЫЙ_КАТАЛОГ_СБОРКИ`. Сценарий формирует неподписанный AAB. Версия 0.40 рассчитана на импорт собственных профилей, а её обновление открывает Google Play.

Прототип VPN для Android с маршрутизацией для Telegram и ChatGPT. Сетевое ядро также запускается на Mac с Apple Silicon как локальный SOCKS5-прокси по адресу `127.0.0.1:17680`. Оно оставляет системное подключение Mac в прежнем состоянии.

## Планета и персонажи

Кнопка «Серверы» или горизонтальный свайп по сцене открывает 3D-глобус. Вращайте его свайпом или перетаскиванием. «К серверам» возвращает исходный вид. Метки вычисляются по координатам города и скрываются на обратной стороне планеты. Текущие подсети Софии, Цюриха и Кишинёва определяются по [геоданным AlexHost](https://alexhost.com/alexhost_geofeed.csv). Контуры суши взяты из [Natural Earth](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/). Профили без подтверждённой локации остаются доступны в списке.

Лис в верхнем левом углу открывает настройки. Переключатель «Сократить анимацию» отключает движение персонажей. Системная кнопка «Назад» закрывает открытый диалог, затем карту.

## Приоритеты на главном экране

Перетащите профиль за ручку справа, чтобы изменить его место в списке под планетой. На компьютере можно также сфокусировать ручку и нажать ↑ или ↓. Порядок сохраняется на устройстве. Принц запускает верхний профиль. При включённой привязке приложений совместимые профили показаны первыми, а прежний порядок восстанавливается после выключения привязки.

Кнопка «Подключить» использует выбранный профиль либо автоматический режим. Нажатие на строку профиля выбирает его вручную.

## Профили и переключение

В графической версии 0.5 нажатие на Принца запускает соединение, а «Домой» вызывает штатное отключение. Лис открывает настройки. Через «+» можно получить комплект по коду, импортировать ZIP или добавить личный профиль VLESS XHTTP по ссылке, из изображения QR-кода либо вручную. Подписки принимаются по HTTPS. Для остальных протоколов используйте комплект ZIP. Собственные профили сохраняются при обновлении комплекта.

Сборки графической версии находятся в `artifacts/0.5-journey/`. Для повторной сборки Android используйте `build_android.zsh`, для Mac с Apple Silicon выполните `zsh build_macos.zsh КАТАЛОГ_ДВИЖКОВ НОВЫЙ_КАТАЛОГ_СБОРКИ`.

| Протокол | Файл профиля | Движок |
| --- | --- | --- |
| VLESS + XHTTP/3 с TLS | JSON Xray | Xray |
| NaiveProxy HTTP/3 | JSON | sing-box на Mac, NaiveProxy на Android |
| TrustTunnel HTTP/3 | TOML со встроенным CA | TrustTunnel CLI |
| AmneziaWG 3.1 | INI `.conf` | AmneziaWG-Go |
| Mieru v3 | клиентский JSON | Mieru |
| VLESS + XHTTP + REALITY | JSON Xray | Xray |

Главный маршрут выбирается по HTTPS-проверкам `api.telegram.org` и `chatgpt.com`. Для этих сервисов можно выбрать разные профили. При первом сбое проверка повторяется. Если соединение через выбранный профиль не устанавливается, новый запрос пробует исправный резерв. Уже открытые TCP-сессии переподключаются средствами приложений.

TCP к доменам `.ru`, `.su`, `.рф`, локальным сетям и префиксам RU из реестра RIPE идёт напрямую. Российская принадлежность IP определяется по выделенным диапазонам из снимка RIPE, а не по фактической геолокации каждой точки CDN. Android использует TUN и сопоставление DNS-запросов с именами доменов. В этом прототипе общий UDP-трафик и голосовые вызовы через прокси не поддерживаются.

## Запуск на Mac

Из каталога с этой инструкцией и исходными архивами в родительской папке соберите приватный набор для Mac. Номер `06` используется в этом примере отдельно от профилей телефона.

```sh
python3 prepare_profiles.py .. ./profiles-mac --user 06 --platform macos --underlay en0
```

Распакуйте `Route-macOS-arm64.zip` и запустите:

```sh
zsh ./run-macos.zsh /absolute/path/to/profiles-mac -underlay en0
curl --noproxy '' --socks5-hostname 127.0.0.1:17680 https://api.ipify.org/
```

`en0` использовался на проверенном Mac. Для маршрута по умолчанию опустите `--underlay` при подготовке файлов и `-underlay` при запуске. Можно передать `-status /absolute/path/to/health.json`, чтобы получить результаты проверок по профилям.

## Импорт на Android

```sh
python3 prepare_profiles.py .. ./profiles-android --user 03 --platform android
(cd profiles-android && zip ../Route-Profiles.zip ./*)
```

В приложении выберите «Импортировать ZIP», затем «Подключить». Архив содержит учётные данные и остаётся приватным. APK их не содержит.

Для рабочих серверов Mieru и REALITY укажите существующие клиентские JSON в параметрах `--mieru` и `--reality`. В этой проверке приложению передали четыре действующих профиля для `185.216.44.33`. На Mac Mieru и REALITY проверили на локальных тестовых серверах.

### Восстановление VPN на Android

При потере сети приложение сохраняет VPN-интерфейс и ждёт возвращения связи. После смены сети или остановки процесса маршрутизации оно перезапускает передачу через выбранный профиль. При повторных сбоях интервал между попытками растёт до 15 секунд. Ручное отключение останавливает также автоматическое восстановление.

## Обновление приложения

В настройках выберите «Проверить обновления». Приложение проверит номер сборки по HTTPS и предложит скачать APK или ZIP с сайта «Маршрута», если опубликована более новая версия. На Android обновление подтверждается в системном установщике. На Mac распакуйте ZIP и замените приложение. Для перехода со сборки без этой кнопки скачайте новую версию с сайта.
