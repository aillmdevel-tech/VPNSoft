# Редизайн сцены «Маршрут»: стиль, свет, модели, VFX, геймификация

Статус: согласован 2026-11-20 (кроме бюджета размера и шрифта), следующий — этап 0.
Область: только `android/assets/journey/` (общая для Android WebView и macOS WKWebView) + сборка ассетов. Сетевое ядро, Java/Swift-логика и мост `RouteHost` не меняются.

## 1. Что есть сейчас (аудит)

- Экран: `index.html` + `journey.js` (49 КБ, вся логика UI, мост `RouteHost.post` / `window.routeState`), `style.css` (39 КБ), `motion.js` + `motion-textures.js` (анимация Принца/Лиса из 2D-спрайтов).
- Глобус: `globe.js` — свой WebGL1 + 2D-fallback, трекбол, войлочная текстура (`powder-texture.js`), рельеф (`elevation.js`, 700 КБ), солнце по реальному времени, снег со «стиранием» пальцем, кратеры по тапу, краб в океане, метки городов (sofia/zurich/chisinau/vilnius).
- Фазы: `home → travel → connected → return`, плюс «Сократить анимацию» (`still`) и `prefers-reduced-motion`.
- Ограничения среды (жёсткие):
  - Загрузка с `file:///android_asset/` и `loadFileURL`; CSP `default-src 'none'; script-src 'self' file:; connect-src 'none'` → **никаких fetch/XHR/ES-модулей**. Модели и текстуры — только внутри классических JS-файлов (base64) или `<img>`.
  - Мин. Android 11 (API 30), WebView с WebGL2 почти везде, но нужен fallback.
  - Локализация через `locales/build.py`: кириллические строки в `index.html`, `journey.js`, `globe.js` ищутся регэкспом — новые строки класть туда же и в `locales/en.json`, `es.json`.
  - Размер: сейчас ассеты ~2.3 МБ.

## 3. Технический подход (предложение)

- **Three.js 0.187** (стек GameFactory) + `postprocessing` (Bloom, Vignette, SMAA, ToneMapping) + `three.quarks` или свои частицы + `gsap`.
- Сборка: `web/` с Vite → **один классический IIFE-бандл** `journey3d.js` в `android/assets/journey/`; GLB вшивается как base64 (`?inline`), сжатие Draco/Meshopt, текстуры KTX2/WebP. Скрипт `tools/web-preview/serve.zsh` остаётся превью.
- `journey.js` и мост не трогаем по контракту: новый модуль реализует то же API, что `window.RouteGlobe` (`locations`, `create(element, markers, placeActors)` …). Старый `globe.js` остаётся как fallback без WebGL2 / при `still`.
- Свет: hemisphere (небо/земля) + тёплый directional «солнце» с мягкими тенями (PCFSoft, одна карта), rim-подсветка Fresnel на океане и атмосфере, ACES/AgX тонмаппинг, лёгкий bloom на метках и звёздочках.

## 4. Модели (Blender MCP, стилизация «clay»)

Все — low-poly, мягкие фаски, вертекс-цвета/палитровая текстура 256 px, бюджет ≤ 60 k треугольников на сцену.
1. Планета: сфера-океан + суша из Natural Earth, выдавленная с бортиком (как у острова), горы/снежные шапки, леса инстансами.
2. Города серверов (маленькие «островки-диорамы», как в реф. 1): София (собор с золотыми куполами), Цюрих (шале + Альпы), Кишинёв (крепость), Вильнюс (башня), «Автовыбор» (кластер небоскрёбов). Используются и на глобусе, и как иконки в списке (рендер в WebP).
3. Декор: облака-попкорн (3 вида), самолётик, кораблик, лодка, деревья (ель/лиственное/пальма), камни, пирамиды.
4. Персонажи: Принц (3D, чиби, шарф физикой-цепочкой) и Лис (аватар/настройки). Источник: генерация по текущим спрайтам (`generate_3d`) или ручная лепка, затем риг + 4–5 клипов (idle, wave, walk/hop, celebrate, sleep).
Ассеты: свои или CC0 (Poly Pizza/Poly Haven), список лицензий в `docs/ASSET_LICENSES.md`.

## 5. VFX и интерактив

- Динамические облака на орбите (дрейф, тень на поверхности), раздвигаются при свайпе.
- Погода по зонам: снег над полюсами/горами (частицы + существующее «стирание снега» пальцем сохраняем), дождик из тучки при тапе по облаку, радуга после.
- Тап по суше: «поп» дерева/цветка; тап по океану: всплеск, кит/краб выпрыгивает; двойной тап — существующий кратер → заменить на «фейерверк/конфетти».
- Подключение (`travel`): пунктирная дуга дом → город, Принц летит на самолётике/воздушном шаре, камера плавно доворачивает; `connected` — флажок-пин, вспышка, конфетти; `return` — обратный полёт.
- День/ночь по реальному солнцу (уже есть) → огоньки городов на ночной стороне.
- UI-джус: GameFactory UIFX (пресет «Roblox Cartoon» / «Playful Jelly»): пружинные нажатия, pop-in карточек, звуки CC0 с регулятором и выключателем.

## 6. Геймификация = физические игрушки с планетой + паспорт

Главное (решение Alex): приятные **физические взаимодействия и приколы** с планетой, а не очки/подарки.
- **Астероиды**: свайп из-за края экрана или долгий тап по небу → метеорит летит по дуге с хвостом, удар: вспышка, ударная волна по воде/суше, кратер-«вмятина» (деформация вершин, затягивается за ~10 с), разлёт деревьев/камней частицами-обломками с физикой, лёгкая тряска камеры, звук «бум».
- **Взрывы и цепные реакции**: попадание в облако — облако разлетается на «попкорн»-шарики, которые падают дождём; в вулкан — извержение лавой; в океан — цунами-кольцо и всплеск, кит/краб подпрыгивает.
- **Динамика планеты**: инерционное вращение с «пружиной» (бросок свайпом, затухание, вобл), сжатие-«желе» при тапе, облака и самолёты реагируют на ветер от быстрого вращения, снег слетает с полюсов при сильной прокрутке.
- **Погодные явления**: тап по туче — гроза с молниями, удержание — торнадо-воронка, которое крутит деревья; снегопад/метель, радуга после дождя, северное сияние на ночной стороне.
- **Существующее сохраняем**: стирание снега пальцем, кратеры по тапу, краб.
- Физика: Rapier (стек GameFactory) только для обломков/шариков, либо своя простая баллистика, если Rapier раздует размер (решить на этапе 4 по замеру).
- **Паспорт путешественника** (подтверждено): штамп города при первом подключении через сервер, счётчик стран и дней, экран паспорта со штампами-«печатями».
- Не делаем: ежедневные подарки, XP, премиум. Хранение — `localStorage` (macOS: WKWebView `nonPersistent` → для паспорта нужен persistent store или сохранение через мост `route`).

## 8. Открытые решения

Ответы Alex 2026-11-20:
- Движок: **Three.js + модели** (IIFE-бандл, модели вшиты, старый globe.js — fallback).
- Геймификация: **физические приколы с планетой** (астероиды, взрывы, динамические явления) + **паспорт и штампы**. Подарки/XP — нет.
- Персонажи: **Принц и Лис оба в 3D**, по текущим спрайтам, с ригом и анимациями.
- Тема: **светлый день + ночь по реальному солнцу**.
Открыто: бюджет размера APK (предложение ≤ +5 МБ), шрифт.
